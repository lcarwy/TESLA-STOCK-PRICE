# 特斯拉（TSLA）上市 16 年股价走势视频

用 Python 生成的股价走势动画视频，适合发 B 站 / 视频号。

成品：[`output/tsla_stock_history.mp4`](output/tsla_stock_history.mp4)（1920×1080，60fps，约 93 秒，带合成背景音乐）

## 视频结构

| 时间 | 内容 |
| --- | --- |
| 0–3s | 片头：特斯拉 TSLA · 上市 16 年股价走势 |
| 3–76s | 走势动画：曲线从 2010 年 IPO 画到 2026-10-23，坐标轴随股价自动缩放；顶部实时显示日期、月收盘价、月涨跌（红涨绿跌）、IPO 时投入 1 万美元的现值；18 个大事件依次弹出注释 |
| 78–84s | 换成对数坐标回顾全程，标出关键高低点 |
| 84–93s | 「16 年成绩单」：发行价、最新价、累计涨幅（约 328 倍）、年化收益率（约 42.6%）、1 万美元现值、最大回撤 |

## 数据

`data/tsla_monthly_close.csv`：2010-06 到 2026-10 共 197 个月的**月收盘价**，已按 2020 年 1 拆 5、2022 年 1 拆 3 两次拆股调整（特斯拉从未派息）。

- 数据来源：StatMuse 月度表格、Digrin 月度价格（通过网页检索获取），`source` 列逐月标注来源。
- 2010-08 至 2010-10 取自 StatMuse 周收盘数据。
- 2010-07、2013-01、2013-02、2019-02、2019-04、2023-02 这 6 个月未查到，用前后月份**线性插值**，视频里对应月份的价格标签会注明「缺失月份插值」。
- 2026-10 为 10 月 23 日收盘价 $372.22（当月尚未结束）。
- 视频中所有数字都按月收盘价计算，与按日收盘价计算的最高价、最大回撤会有差异。

想要逐日精度，可以把 CSV 换成 Yahoo Finance 等来源的日线数据（月份列改成日期即可，脚本只依赖 `month`/`close` 两列和顺序）。

## 重新生成

依赖：Python 3、`ffmpeg`，字体 Inter 和文泉驿正黑（WenQuanYi Zen Hei）。

```bash
pip install matplotlib numpy
python3 make_video.py --fps 60 --music      # 输出 output/tsla_stock_history.mp4
python3 make_video.py                       # 30fps、无音乐，渲染更快
python3 make_video.py --preview 12 40 80    # 只导出这几个时间点的截图，用于调版式
```

- 大事件注释在 `make_video.py` 顶部的 `EVENTS` 列表里，可增删改。
- 各年份的播放速度在 `month_seconds()` 里调整。
- 背景音乐由 `bgm.py` 用 numpy 合成（A 小调 Am–F–C–G 循环，100 BPM），无版权问题；也可以导出无音乐版本后在剪映里换成自己的 BGM。

> 历史表现不代表未来收益，视频内容仅供参考，不构成任何投资建议。
