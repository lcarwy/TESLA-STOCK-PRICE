# 特斯拉（TSLA）上市 16 年 · 3D K 线故事视频

仿照 B 站 @湾林Studio《CS饰品五年大盘涨跌幅可视化》的风格，用**按日收盘价**做的特斯拉竖屏股价视频，每个阶段都配有「为什么涨 / 为什么跌」的驱动因素和资本动向解读，结尾用数据给出可视化的买入参考。

成品：[`output/tsla_vertical.mp4`](output/tsla_vertical.mp4)（1080×1920 竖屏，30fps，约 6 分 24 秒，带合成配乐和音效）

## 数据

- `data/tsla_daily.csv`：2010-06-29 至 2026-10-23 每个交易日的 OHLCV（Yahoo Finance，已按 2020 年 1 拆 5、2022 年 1 拆 3 调整；特斯拉从未派息）。周K 由日线聚合。
- `data/tsla_hourly.csv`：最近约两年的 1 小时 K（Yahoo 的上限），每天最后一根小时线对齐到当日官方收盘价。
- 涨跌幅、天数、历史新高、单日跌幅排名、「五次腰斩」、持有期胜率、历史类比、定投回测等数字全部由脚本从价格数据计算（`tsla_video/story.py`）。
- 解读卡中的事件和金额来自当时的公开报道与公告，每张卡底部注明了资料来源（如特斯拉财报与公告、SEC 文件、标普道琼斯指数、S3 Partners、VerityData、美国联邦选举委员会、SpaceX 招股书、彭博、Electrek 等）。
- 华尔街评级与目标价：S&P Global 数据（经 stockanalysis.com，2026 年 10 月），44 位分析师。

## 重新生成

依赖：Python 3、ffmpeg，`pip install skia-python numpy pandas yfinance`（skia 需要系统库 `libegl1`）。

```bash
python3 scripts/fetch_daily.py              # 更新日线 / 小时线数据
scripts/fetch_fonts.sh                      # 下载字体（思源黑体 SC、Barlow Semi Condensed，均为 SIL OFL 开源授权）
python3 make_vertical.py --preview 30 130   # 导出几帧截图检查版式
python3 make_vertical.py                    # 完整渲染 → output/tsla_vertical.mp4
```

- 分镜在 `tsla_video/story.py`：用 `Timeline.chapter(...)` 逐章定义 K 线走势时长、停留时长、面板文案、解读卡内容和音乐情绪，时间轴自动累加。
- 画面：`tsla_video/chart.py`（3D K 线）、`tsla_video/scene.py`（HUD、面板、解读卡、结论图表）、`tsla_video/effects.py`（粒子特效）。
- 配乐：`soundtrack.py` 按分镜的情绪段落合成鼓点、和声和音效，解读卡期间自动降低鼓点方便阅读，无版权问题。

> 结论部分是对历史数据的统计，存在幸存者偏差，不构成任何投资建议。股市有风险，投资需谨慎。
